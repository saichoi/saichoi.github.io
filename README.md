# saichoi.github.io

`https://saichoi.github.io/` 에 보이는 대표 페이지입니다.

- `index.html` — [Asana Log](https://saichoi.github.io/asana-log/) 소개와 바로가기. 검색 엔진(네이버 등) 소유 확인 태그도 여기에 넣습니다.
- `robots.txt`, `sitemap.xml` — 검색 로봇 안내. `robots.txt` 는 호스트 맨 위에 있어야 해서 이 저장소에 둡니다.

`main` 에 push 하면 GitHub Pages 가 자동으로 반영합니다.
